## 🎯 Synopsis

This project characterizes the **voltage–current (V–I) relationship** of a 5mm blue LED. Forward voltage was incrementally applied and the corresponding current measured. The data was plotted in Python to visualize the nonlinear I–V curve, demonstrating the typical exponential turn-on behavior of an LED.

## 📊 Results

<p align="center">
  <img src="Blue LED V-I Curve.png" alt="Blue LED V-I Curve" width="500"/>

The characteristic curve shows the expected behavior: negligible current below the threshold voltage (~2.5 V), followed by a rapid exponential increase in current.
